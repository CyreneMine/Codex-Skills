# 授权课程离线归档

把实际可访问的课程内容整理成可验证、可搬移的离线资料。先成功保存并验证一个课时，再按真实目录批量处理。

## 权限和范围

- 使用用户自己的有效观看权限。购买声明支持登录查看，不证明其他课程、全部账号内容或隐藏接口也已授权；以当前课时正常播放及正常授权响应为依据。
- 优先使用网站下载或官方离线方式。开发者检查、脚本请求依当前工具规则和用户授权执行，下载授权不扩大安全设置权限。
- 工具明确拒绝 URL、协议、来源或动作时，不用原始 CDP、系统命令、代理调整或其他浏览器绕过同一拒绝。工具能力不足、接口超时、权限拒绝分别记录。
- 不伪造授权、枚举未授权课程、绕过付费墙或提取 DRM/CDM 密钥。正常播放器提供的 HLS AES-128 密钥与 DRM 授权要区分。
- Cookie、临时签名、密钥响应、身份页面和课程媒体只留在本地任务目录，不进入 Skill、Git 或公开输出。

## 判断真实状态

1. 阅读当前浏览器工具文档，让用户亲自登录。仅检查任务需要的账号页面和课程。
2. 确认课程名称、真实目录、视频/文字/资料/在线作业、选修范围和保存位置。任务数量不能直接当成视频数量。
3. 接口超时或没有返回文件路径不等于下载失败。先核对实际落盘文件和浏览器下载记录，不默认实际目录是系统 Downloads，再决定是否重试。
4. 用户手动页可播而受控页空白时，先对照正确标签页和框架，保留能播放的页面；不要反复刷新消耗临时授权。

## 单课验证

用受支持的开发者接口观察正常播放，识别初始化请求、主/媒体清单、分片和密钥。跨域播放器事件可能在子框架，使用工具已暴露的会话，不猜 ID 或未支持的 CDP 方法。

普通 HLS 可使用 [`scripts/archive_hls.py`](scripts/archive_hls.py)，先读 `--help`。脚本需要 Python、FFmpeg/ffprobe，加密分片另需 `cryptography`；优先发现现有运行时，不无故安装软件。

- 每课获取当前授权参数，按实际请求形状读取，不批量猜 URL。m3u8 文件不是已经下载的视频。
- 选择用户要求的清晰度；同课重复的同一密钥 URI 只取一次并在内存复用。不要假定签名链接和密钥响应可重复读取。
- 非标准密钥长度先核对官方客户端和当前版本，不截取、补齐或暴力尝试，不把错误响应当密钥；未知格式停止。
- 游习堂/EduSoho/气球云的实测适配见 [`references/edusoho-qiqiuyun.md`](references/edusoho-qiqiuyun.md)，仅在当前站点和正常授权流程相符时读取。

先核对一个课时的实际文件、完整分片、源时长及音视频流，并完整解码或实际播放样本。验证通过前不扩大到全课，不宣称可以离线播放。

## 批量归档

- 从真实呈现目录或已确认只读接口枚举课时，过滤模板占位符，保留课时 ID、顺序、名称、类型及选修标记。
- 使用少量并行任务，按实际错误和负载调整。每课独立缓存，匹配资源身份、清晰度、分片结构及缓存哈希后续传。
- 只有验证通过才记录成功，失败、进行中及未覆盖的在线交互单列。先核对已有成功记录，避免新签名触发重复下载。
- 资料保留原始字节，以课时或资料 ID 区分同名源码版本；不要把所有同名文件覆盖在同一路径。
- 文字页必须有正文。空容器需要核对正常客户端的只读接口及请求头；配图本地化后先 URL 解码再检查引用，不能把只有自制标题的页面计为成功。
- 下载任务不自动授权开始在线作业、答题、提交或评分；无法只读导出时保留入口并说明。

## 验证、目录与搬移

用 [`scripts/library_tools.py`](scripts/library_tools.py) 的 `audit` / `index` 处理公开清单，格式见 [`references/library-manifest.md`](references/library-manifest.md)。生成自包含 HTML、相对链接和哈希，不索引认证文件。

结构/路径检查、时长与流检查、完整解码、浏览器播放是不同证据。只抽检一个视频时不称全部逐帧验证；本地 HTTP 播放不等于 `file://` 或断网测试。

用户要求跨盘移动时，核对明确的源、目标和冲突。复制后逐文件 SHA-256 一致，再删除已核对的原目录；任何差异都保留原目录。没有移动请求时不删原件。

最后核对实际数量、失败项、引用和残留 `.part`，清理本次创建的认证材料。交付路径、大小、检查结果及仍需在线访问的内容。

## 维护验证

运行 [`scripts/self_test.py`](scripts/self_test.py) 检查本地合成 HLS、单次密钥、失败续传、跨来源请求头隔离和目录引用；不访问真实账号。另运行官方 `quick_validate.py <本技能目录>`。

真实流程来源和证据边界见 [`references/workflow-evidence.md`](references/workflow-evidence.md)。
