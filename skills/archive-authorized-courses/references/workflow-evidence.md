# 来源与验证边界

来源为 2026-10-25 至 2026-10-26 的一次用户自有已购课程归档。用户亲自登录，明确允许开发者网络检查、本地脚本和后续指定目录搬移。

当次保存 82 视频（含选修）、169 资料、4 文字课时与 8 配图；视频逐课核对分片、时长、流及哈希。仅第一课完整解码和本地 HTTP 播放，没有声称全课逐帧测试。两项在线作业未开始、答题、提交或计为离线内容。

原始账号材料、课程媒体、带身份页面和厂商客户端均不随 Skill 发布；这次成功不保证未来站点不变。

| 实际观察 | 可复用决策 |
| --- | --- |
| 下载接口超时但文件已落盘，误重试产生工程包副本 | 先核对实际文件、下载记录与真实目录 |
| 手动页可播，受控刷新后框架空白 | 对照正确标签页和框架，不当成账号无权限 |
| 播放器请求在跨域子框架 | 使用工具已暴露的子会话 |
| HTTP 200 JSONP 仍是授权错误 | 核对结构、错误字段与当前参数 |
| 非 16 字节密钥、格式版本随请求变化 | 核对官方客户端当前格式，未知停止 |
| 49 个密钥标签复用一个 URI，重复请求返回 400 | 同课内存缓存密钥，不重复消耗链接 |
| 直接 FFmpeg 遇到无扩展名、代理协议和格式封装问题 | 先诊断，改为授权分片解码后本地合并；未改全局代理或 TLS |
| 文字原页是空容器，初版只有标题 | 使用正常只读正文接口及 API v2 头，再检查正文与图片 |
| 中文图片路径被百分号编码 | 解码后查文件，另实测图片加载 |
| 工具明确拒绝 file 协议 | 停止该协议自动预览，不切换通道绕过 |
| 用户要求跨盘移动 | 269 文件逐一 SHA-256 相同后才移除原目录 |

维护时分别记录官方结构校验、文档链接、合成媒体端到端测试、新对话触发和真实站点回归。新脚本的合成测试不等于已经在新网站或新账号上验证。
